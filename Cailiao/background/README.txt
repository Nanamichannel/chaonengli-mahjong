背景图片文件夹
================

换背景的方法：
1. 把任意图片（png / jpg / jpeg / webp / bmp / tga / avif）放进这个文件夹。
2. 重新运行游戏即可。

规则：
- 游戏会按文件名排序，取第一张作为背景。
  （所以想指定某张图，把它命名得靠前一点，例如 00_xxx.png）
- 不同分辨率会自动「等比缩放并铺满整屏」：
  图片比例和屏幕不一致时，多出来的部分会被裁掉，不会变形、不会留黑边。
- 窗口大小变化时会自动重新适配。
